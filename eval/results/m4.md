# M4 results: fee-aware batching

100 of 100 M0 users planned with each planner (seed menu, synthetic per-restaurant fees). Baseline: M1 with batching off.

| Target | Goal | M4 batching | M4 batching + pickup |
|---|---|---|---|
| Median weekly fee savings vs M1 | ≥ 25% | 26.8% ✅ pass | 32.5% ✅ pass |
| Valid-week rate | no drop vs M1 (67.0%) | 74.0% ✅ pass | 74.0% ✅ pass |
| Variety (median distinct items) | drop ≤ 2 vs M1 (20.0) | 19.0 (drop 1.0) ✅ pass | 19.0 (drop 1.0) ✅ pass |
| Food-safety window violations | 0 | 0 ✅ pass | 0 ✅ pass |
| Budgets only possible with batching | report | 7 | 7 |

| Planner | Valid weeks | Median fees / week | Median orders / week | p95 planning time |
|---|---|---|---|---|
| M1 (batching off) | 67.0% | $98.58 | 21.0 | 2.4 s |
| M4 batching | 74.0% | $71.96 | 15.0 | 2.3 s |
| M4 batching + pickup | 74.0% | $66.72 | 15.0 | 2.2 s |

Median user (user 82): fees $106.08 a week with M1 → $77.70 with batching → $77.70 with batching + pickup.

Fee savings compare each user's fees with M1's fees for the same user; users without a valid week from both planners are left out of that median. All fees are a synthetic model.
